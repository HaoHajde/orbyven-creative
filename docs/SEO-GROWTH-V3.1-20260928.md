# ORBYVEN SEO V3.1 — Organic Growth

Implemented 28 September 2026 without redesigning the homepage, templates or workspace.

## Changes
- Added an indexable topic-cluster layer across commercial landing pages, guides and case studies.
- Related-link blocks now explain why each next page matters instead of exposing only small generic pills.
- Topic clusters deliberately filter individual template/demo routes and private workspace/admin routes because those are noindex targets.
- Service cards now link to the matching commercial pages with descriptive anchor text.
- /servicii also links directly to the case-study hub.
- Invitation pages now cross-link wedding, baptism and 18th-birthday invitation categories as one event topic cluster.
- SEO shell footer now exposes service, case-study and guide hubs.
- Added offline regression tests for the new internal-link architecture.

## Deliberately unchanged
- No keyword-stuffed pages or duplicated city pages were created.
- Demo URLs remain available to users as visual proof, but are not used as preferred organic cluster targets.
- No ranking, traffic, indexing or Core Web Vitals claim is made without Search Console / field data.
