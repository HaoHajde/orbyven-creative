# ORBYVEN — registru drepturi media, înainte de comercializare

Un fișier prezent în repository sau un URL public NU dovedește o licență comercială. Materialul clientului NU devine automat publicabil în portofoliul ORBYVEN. Nu adăuga imagini doar pentru că apar în Google Images.

| Template nunta/demo | Fișier audio demo și imagini persoane | Licență muzică pentru sincronizare / distribuire online și drept la imagine / autorizare pentru persoane și clienți | NEVALIDAT |

| Template-uri botez/majorat | Copii, persoane, logo-uri, fonturi, fotografii | Licență adecvată; consimțământ/politică pentru minori când este cazul; titulari drepturi | NEVALIDAT |
| Testimoniale / studii de caz | Nume client, cifre, capturi, testimonial | Aprobare pentru publicare și exactitatea afirmațiilor | NEVALIDAT |
| Fonturi externe | URL / pachete pentru fiecare font | Licență și condițiile de servire, identificarea solicitărilor transmise terților | DE INVENTARIAT |

## Câmpuri de completat per asset

ID; cale/referință; proprietar/titular; sursă; autor/credit; document licență/acord; domeniu de utilizare; comercial/derivate/distribuire/AI training după caz; durata; teritoriu; restricții de atribuire; expirare; persoană responsabilă; locul unde este arhivată dovada; dată verificare.

Când dovada lipsește: înlocuiește asset-ul cu unul produs și licențiat corect; nu inventa atribuire și nu interpreta accesibilitatea publică drept autorizație.
